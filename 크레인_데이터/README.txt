크레인 데이터 + 분석 코드
=====================================================

[코드 설명]  (basePath 모두 자동 인식)
  Spec3_9.m            한 폴더 → 9채널 주파수 스펙트럼 (Raw/속도/포락 창 3개)
  RMS3_9.m             한 폴더 → 9채널 RMS만 출력
  Spectrogram3_9.m     한 폴더 → 9채널 스펙트로그램 (시간-주파수)
  NewCompare3_9.m      여러 데이터셋을 겹쳐 비교 (정상 vs 결함 등 오버레이 스펙트럼)
  Combine5cyc_UpDown.m 한 날짜 5개 사이클의 상승/하강만 합쳐 9채널 스펙트럼
                       (NewCompare 와 동일 결과)
  siganl_anal.m        단일 채널 다목적 뷰어
                       (시계열 / RMS / 스펙트럼 / 스펙트로그램 / 사이클별)

  공통 지정값: targetDate(예 260811_1) / targetRPM(60·70·80) /
              condName(정상·베어링외륜 등) / viewMode(0전체·1상승·2하강)

[경로 설정 - 자동]
  6개 코드 모두 basePath 를 '이 스크립트가 든 폴더의 상위(=패키지 루트)'로
  자동 인식 → 폴더를 옮기거나 이름 바꿔도 그대로 실행됨.
  ※ getspec/convmeas(PHM toolbox)는 MATLAB 에 연동돼 있다고 가정.

[분할 규칙]
  1사이클 = 상승(mw1=1) → 하강(mw1=3), 경계=각 상승런 시작.
  로그(state_log.csv)의 원본 타임스탬프 보존 → 재로드 시 국면(codePS) 매핑 정상.
  전 조건 정확히 5사이클로 분할됨(사이클당 9~12 파일).
